B8A1: Assignment - Problem Solving with TypeScript & OOP

Complete solutions for the TypeScript & OOP assignment, covering basic types, tuples, generics, interfaces, OOP principles, and asynchronous programming.

##  Project Structure

* solutions.ts: Contains all 8 TypeScript problem solutions.
* type-vs-interface.md: Blog post comparing Type Aliases and Interfaces.
* type-narrowing.md: Blog post explaining Type Narrowing in TypeScript.

##  Summary of Solutions (solutions.ts)

1. multiplyValue: Handles multipliers with a default value of 2 (correctly supports 0).
2. processInput: Uses typeof type narrowing for string, number, and boolean.
3. formatCoordinate: Formats a readonly tuple coordinate into a location string.
4. concatenateArrays: Generic function with rest parameters to combine arrays.
5. getPopularCourses: Filters course objects using the Course interface.
6. pluckValues: Generic function with keyof constraints to extract property values.
7. Employee & Manager: OOP implementation using protected, private, and inheritance.
8. validateAgeAsync: Asynchronous function returning a Promise<string> with error handling.
